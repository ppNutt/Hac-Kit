# Tauri + React + Typescript

This template should help get you started developing with Tauri, React and Typescript in Vite.

## Macro playback

The Auto Clicker's Start button and global Toggle macro playback shortcut (Ctrl+P
by default) both use the selected movement speed and loop setting. Press Ctrl+P
once to start playback and again to stop, including during a loop and while
another app is focused. Settings are kept for the current app session, including
when switching pages. Changes apply to the next playback; the Auto Clicker's Stop
button also ends playback.
